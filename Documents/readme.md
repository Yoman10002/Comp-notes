# Documents & Study Notes Directory

This directory stores all theory, conceptual notes, and reference materials.

## Structure

*   **`Notes/`** - Personal summaries, revision notes, and self-made cheat sheets.
*   **`Official Notes/`** - Direct handouts, PDFs, and reference files provided for syllabus.

## Guidelines for Adding Notes
*   Keep document names clear and descriptive (use underscores instead of spaces, e.g., `Introduction_to_Python.md`, `Handwritten_notes.png`).
*   Ensure all official PDFs or PNGs are correctly placed in the `Official Notes/` subfolder.
