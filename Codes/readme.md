## Standard Script Documentation Template

To ensure every script is easy to learn from, each code file should ideally follow or include comments covering the following core sections:

1. **Syntax Structure:** Breakdown of how the code or command is written mechanically.
2. **Simple Explanation:** Plain-English summary of what the code does line-by-line.
3. **Understandable Uses:** Real-world scenarios or problem types where this pattern is applied.
4. **Variations:** Alternative ways to write or execute the code to achieve different outputs (e.g., ascending vs. descending loops, step changes).
5. **Common Mistakes:** Frequent syntax or logic errors beginners run into and how to avoid them.
